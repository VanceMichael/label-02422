## 运行测试

### 运行所有测试
```bash
cd backend
mvn test
```

### 运行特定测试类
```bash
mvn test -Dtest=ArticleServiceTest
mvn test -Dtest=SecurityTest
mvn test -Dtest=PermissionTest
mvn test -Dtest=XssFilterTest
mvn test -Dtest=SqlInjectionTest
mvn test -Dtest=RateLimitTest
mvn test -Dtest=TokenExpirationTest
mvn test -Dtest=AuthorizationTest
```

### 运行特定测试方法
```bash
mvn test -Dtest=ArticleServiceTest#testLikeArticle
```

### 生成测试报告
```bash
mvn test
# 报告位置: target/surefire-reports/
```
