## 技术实现细节

### 1. 认证流程
```
用户登录 -> 验证用户名密码 -> 生成JWT Token -> 返回Token
后续请求 -> 携带Token -> JwtAuthenticationFilter验证 -> 设置SecurityContext -> 访问资源
```

### 2. 权限控制
```
@PreAuthorize("hasRole('ADMIN')") - 仅管理员可访问
@PreAuthorize("hasAnyRole('USER', 'ADMIN')") - 登录用户可访问
无注解 + permitAll() - 公开访问
```

### 3. 文章点赞流程
```
用户点赞 -> 检查是否已点赞 -> 插入点赞记录 -> 更新文章点赞数 -> 事务提交
```

### 4. 文件上传流程
```
接收文件 -> 验证大小 -> 生成唯一文件名 -> 保存到磁盘 -> 记录到数据库 -> 返回文件信息
```

### 5. 操作日志记录
```
@OperationLog注解 -> AOP拦截 -> 记录操作信息 -> 保存到数据库
```

### 6. 接口限流
```
请求到达 -> RateLimitInterceptor拦截 -> 检查IP限流 -> 通过/拒绝
```

### 1. JWT认证实现
**难点**: 如何实现无状态认证，同时保证安全性？

**解决方案**:
- 使用JWT生成Token，包含用户ID、用户名、角色信息
- Token有效期2小时
- 自定义JwtAuthenticationFilter拦截所有请求
- 验证Token有效性后设置SecurityContext
- 使用HS512算法签名

### 2. XSS攻击防护
**难点**: 如何防止用户输入的恶意脚本？

**解决方案**:
- 自定义XssFilter过滤器
- 包装HttpServletRequest
- 对所有参数进行HTML转义
- 使用Spring的HtmlUtils工具类

### 3. 接口限流
**难点**: 如何防止恶意请求和爬虫？

**解决方案**:
- 使用Google Guava的RateLimiter
- 基于IP地址限流
- 自定义@RateLimit注解
- 拦截器实现限流逻辑
- 缓存限流器实例

### 4. 文章全文搜索
**难点**: 如何实现高效的文章搜索？

**解决方案**:
- 使用MySQL的FULLTEXT索引
- 配置ngram解析器支持中文
- MATCH...AGAINST语法实现全文搜索
- 对标题和内容建立联合全文索引

### 5. 跨平台Docker镜像
**难点**: 如何支持ARM和X86架构？

**解决方案**:
- 使用多阶段构建
- 构建阶段使用--platform=$BUILDPLATFORM
- 运行阶段使用eclipse-temurin:8-jre（跨平台）
- 避免使用alpine等特定架构镜像

### 6. 权限控制
**难点**: 如何实现细粒度的权限控制？

**解决方案**:
- 使用Spring Security的@PreAuthorize注解
- 在Service层检查资源所有权
- 管理员可以操作所有资源
- 普通用户只能操作自己的资源
- 在Controller层获取当前用户信息
